The PocketWorld adapter validates a bounded subset and explicitly rejects prefix
modifiers and known unsupported value forms; it does not claim full RFC 6570 Level 4.
Those forms include square brackets in reserved/fragment values, empty composite
matrix members or an empty scalar with matrix explode, empty values in non-query
exploded maps, non-final empty list members (except exploded query/continuation
lists), and non-final defined empty values in unnamed multi-variable expressions.
The adapter rejects these inputs before any resource read; it never removes empty
values or silently changes the RFC-defined separators. Undefined values and empty
collections retain the standard omission behavior; supported empty strings stay
distinct from undefined values.
