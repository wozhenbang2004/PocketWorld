# 私聊原回答：关闭个人记忆仍可核对已取得的公开出处

适用于普通私人管家的一次原生最终回复。取得网页摘录和让模型读取个人记忆是两回事。关闭个人记忆不新增或放宽联网权限；如果原任务已经实际取得且留存了匿名公开来源，可从原回答的菜单打开「回答来源」。不需去设置开启记忆，也不需重新检索。已带原来源身份的回答维持现有入口与限制。

只读路径核对原私聊保存的消息 ID、修订、原生答复 ID、任务/执行/代次和答案指纹。答复保存时只有匿名取证记录还不显示入口；同一个答复 ID 和指纹随原最终检查点保存后，这条答复才显示入口。只核对这条回复前最后一段原任务的匿名公开搜索、读取或复合检索。工具结果要和原任务的同笔来源事件一致，已遗忘、删除、撤回或缺少精确原证明的内容不读。不会以当前网页、另一轮相同文字或新结果代替旧出处。

「搜索摘要」不是网页正文。「网页摘录」与「网页部分摘录」只显示当时保留的有界文本，不保证覆盖整页，不证明模型确实采用了这个来源，也不证明网页说法已核实。点击「在浏览器打开当前网页」是单独、由主人触发的实时导航，不改变原证据；只有未被隐去参数的原 HTTPS 地址可打开。不从成功返回空正文、失败尝试、回答里的普通链接、登录浏览器、厂商托管检索或手机/文件回执冒认匿名来源。

人工验收，需在该源码构建的应用上完成：

1. 普通私聊关闭个人记忆，明确交办：“只用匿名公开网页，查 Python 官方教程怎样创建和激活虚拟环境；请读正文并给出处。不登录、不使用账号或私人材料。”可先人工核对[Python 官方教程](https://docs.python.org/3/tutorial/venv.html#creating-virtual-environments)。它包含创建 `python -m venv tutorial-env`、Unix `source tutorial-env/bin/activate` 与 Windows `tutorial-env\Scripts\activate` 的示例。这只是站点基准，不是 PocketWorld 已读取的证明。
2. 原任务实际存到正文才应在该回答看到「网页摘录」或「网页部分摘录」和当时保留的文本；返回关闭来源页后仍是原回答。若仅允许搜索、拒绝读取正文，取得摘要时仅看到「搜索摘要」，不会为同一结果凭空标为正文。不授权登录、脚本、上传其他材料或换付费工具弥补缺口。
3. 不联网、一条无出处的普通答复、没有实际保存正文或摘要、直接读取失败：不得从文本 URL 生成来源。缺原终态或只能核对到来源提示但记录已经不可用，打开时应说明没有可准确关联的来源，不显示旧正文。
4. 排队的新输入如得到了同样的回答文字，不能用其后续答复或早先工具回执代替原证明。较早排队答复没有自己的终态证明，原话与历史里的这条都不显示这个入口；下一条只有自己的证明能点亮。旧包提示不回填；切到别的私聊或换代不得把上一视图的迟到内容接到当前回答。
5. 若原事件已按现有功能遗忘，或原私聊/源消息已经撤回，重新打开或选择明细不得看到旧摘录；同轮可能重复引用时也不得绕过遗忘。既有权限、用户拒绝、Book 写入与不同任务范围均不改变。

源码验收不能替代应用取证：官方站点有这些文字不意味着此设备能取得同一段；实际运行的来源回执与这条消息的原生身份匹配后，才能确认端到端。
