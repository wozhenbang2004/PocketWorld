First connection & recovery
  1. Open Pair devices in the existing Windows Companion, or run phone_tasks.py pair --config <existing config>.
  2. Import its invitation in PocketWorld’s device connections page. Review the same fingerprints on both devices and choose the exact phone task scope on the phone.
  3. Start the original bridge, then use Check connection. An expired or revoked scope needs a new explicit review on the phone.

This Desk stays bound to the phone below. A connection failure never switches devices or resubmits work. USB uses the CLI’s explicit serial and boot selection.
