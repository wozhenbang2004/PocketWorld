# 从历史里自己发出的那句话，找到它发起的工作

基线 `be17f08`。在「浏览对话记录」里，助手的回复已有任务入口；如果工作先停下来等确认，助手还没有回复，这条路就断了。只给**有本机登记回执的用户消息**补一个「查看原工作」。不在每条消息下展示执行状态，不创建第二份工作卡，不借这次查看发送、批准或重试。

**身份链。** `AssistantModule` 登记输入后，核对宿主返回的 taskId、runId、epoch，再把消息、client 和 conversation 身份写入回执；`ConversationRepository.messageFromRow` 读取该原消息的回执。历史窗口只接受它们彼此吻合的 accepted / queued / consumed 记录，不信任标题、顺序、相邻回复、导入的元数据或单独的 taskId。点击时由原生端重读私人工作，再核对窗口、原消息版本、归属和执行轮次；不是同一轮就把原因留在原消息下，不改看下一轮。客户端不接收执行权柄。

**设计依据。** 依[十五系统](https://chatgpt.com/space/page_6c522c5579c08191944bb585f4bf5708)与[项目设计规范](../DESIGN.md)，复用已有历史消息动作行、BoardUI Button、Solar 工具图标和 Vaul 阅读抽屉。不引入另一套入口、字体、底色或动画。

| 系统 | 本次取舍 |
| --- | --- |
| 配色与表面、形状与圆角、阴影与材质 | 沿用 ghost 按钮和原消息表面；无新卡片、色标或阴影。 |
| 空间与密度、排版与可读性、内容与文案 | 一项本地化动作；失败的原因贴着该条消息；长文字自然折行。 |
| 组件与状态、图标与符号 | 真按钮配可见动词；无绑定不渲染，读取期间禁重入。 |
| 动效与过渡、手感与性能 | 使用原抽屉；点选后才查原工作，不逐条查工作库，不轮询、不添加动效。 |
| 图像与媒体、数值与监控 | 无封面、计数、百分比；附件输入按原消息回执判定，不展示猜测的进度。 |
| 导航与架构、跨尺寸与输入、反馈与恢复 | 44px 触区；成功后留住原阅读位置和草稿，返回焦点只给同一窗口、消息、版本与任务的入口。选择「在此对话继续」仍是独立操作。 |

**待实机复核。** 保持另一份草稿，打开历史中已登记但尚无助手回复的输入，点「查看原工作」，核对任务及已有待确认项；不按确认，返回，检查原消息位置、焦点和原草稿。再对照一条未经确认的发送、一条仅有同名工作的信息，以及已更换执行轮次的旧回执。此路径不声称已在 Android 或 TalkBack 上验证。
