# 公开 Git 项目导入 · 手机本机开发入口

任务：从公开 HTTPS 仓库的明确分支读取固定版本，核对并创建本机私人项目，再明确打开。对比 DSH-Go 移动引擎/工作区与 and-code 本机克隆（见本项目 phone-development-runtime 研究）；复用 PocketWorld 原生双审阅，不新增 Git、网络、运行器或凭据管道。本轮不是 Android 设备导入验收。

| 系统 | 决定与验收路径 |
|---|---|
| 配色与表面 | 沿用项目 Dialog 表面；错误另有文字，不靠色区分成功。 |
| 形状与圆角 | 一层对话框，步骤不嵌套卡片；长地址和分支能换行。 |
| 空间与密度 | 首层仅地址、精确分支、项目名；工具和范围在审阅时出现。 |
| 排版与可读性 | 步骤标题明显，精确地址和提交完整可读。 |
| 组件与状态 | 同一表单复用 SettingsDialog；查询、停止、确认分别命名。 |
| 动效与过渡 | 沿用 Dialog 开合；步骤切换不加动画、不跳焦。 |
| 图标与符号 | 导入显示动词；联网读取与本机创建不靠符号区分。 |
| 图像与媒体 | 不涉及，无需要识别的媒体，不用图片传递状态。 |
| 导航与信息架构 | 只在项目目录开始；关闭回原目录，完成后明确打开原项目。 |
| 跨尺寸与输入 | 单列表单，键盘可达；窄屏重点看长输入和确认。 |
| 阴影与材质 | 保留已有弹层材质，避免在项目清单叠加诊断侧栏。 |
| 内容与文案 | 说清读取分支、未执行代码、本机创建，不说已上线。 |
| 手感与感知性能 | 明确反馈当前在核对，同一操作可查询，不自动重送。 |
| 数据与监控 | 只呈现原生状态、固定提交、源字节；未知不造进度。 |
| 任务反馈与恢复 | 未决只查原编号；显示明确停止的影响；复用原任务持久记录。 |

未开始联网读取时可跳到已有开发工具准备中心；回来再打开导入，可恢复本次公开地址、分支和项目名。只保留本窗口表单，不会立即准备工具、保存认证或重新提交 Git 任务。此回程需在同一 Android 实机验证。
