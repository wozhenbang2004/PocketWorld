# 主机不可用时打开已保存的原件
原主机任务可直接列出自己在手机上已保存的有限原件，无需由服务器确认当前连接，未保存的冻结文件不混入。点开单个文件才核对原 TaskStore 的 task/版本/相对路径与 AttachmentBook 的实际来源、大小、摘要，再进本机原格式阅读器；返回仍是该工作。源码显示为文本，安装包不安装。旧记录不能核对时停在原任务，不退回私有附件总目录、不找同名文件、不重下。

直接私人主机任务先显示手机侧记录，只有核对到相同原始工作区/操作/作业回执才说“曾接单”。点「查询原主机」才进入该前台原任务的已有查询；回到只看本机或离开前台即关闭这页持续观察。这不是取消主机工作，亦不影响用户另外单独开启的监控。团队代办不借用这个私有入口。

同一版本冻结了至少两份文件时，可以主动勾选一个子集到手机；默认不勾选，也不打包或重新执行。只准原来源同一版本，每份不超过 256 KiB、最多 8 份、整组 512 KiB。先完整核对清单，随后逐份沿已有保存链验证字节与哈希；遇到第一处断线、审阅失效、来源变化或磁盘错误就停。已成功的每一份已有原任务登记，当前项标未确认，后续项未尝试。恢复必须重新选择，已有相同手机原件会重新核其字节后复用。
