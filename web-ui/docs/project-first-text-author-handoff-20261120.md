# 阶段 A｜从原项目交办到具名首作者的一份独立改稿

**决定：**先做一名原本机模型成员、一个已存在且完整可读的小型 UTF-8 文本、一次明确的主人批准。只交私有的原文/改稿差异，不写回工程或副本，不运行命令、不打包、不用其他设备。整树副本与整合（B）暂停。本页是待实现的产品契约；静态依据为本地发布接续树 `a188063671a2763e4d7f77bc01fedb8dab4478d2`，不是设备验收。

**主线：**原私人消息（项目里的[「问管家」](../src/App.tsx#L1866-L1875)也只带项目回到原输入，由主人发送） → 原项目任务的「确认工作计划」 → 原工作如实显示批准或启动回执 → 原作者保存一份独立差异 → 原项目「工作」和原对话同一条消息都打开**这同一份原件**，关闭回各自的原位置。

| 分界 | 复用与下一步 | 必须停下的条件 |
| --- | --- | --- |
| **原计划 → 批准** | 复用 `teams_plan` 的 `planRef/planHash`、原父 `task/run/epoch`、冻结成员/文件和原预算，以及原 `teams_start/start_parent_plan` 的 `approvalId`。A 的审阅只接单一作者与路径，另核原私人消息 ID/版本、原生 project/checkout 与被选文件 SHA；不能假设现有项目 ID 或 `projectContextHash` 就等于已核对这份副本的字节。 | 计划、消息、成员、所选副本或文件字节已变，超限或不是单一对象，停在原审阅。现有团队计划只批准所选文字文件的隔离草稿，并非整树。见 [TeamParentPlan](../../app/src/main/java/dev/pocketengine/features/teams/TeamParentPlan.java#L25-L68)、[原审批投影](../../app/src/main/kotlin/dev/pocketengine/ui/web/PocketWebApprovals.kt#L58-L65)、[TaskStore 原启动领取](../../app/src/main/java/dev/pocketengine/store/TaskStore.java#L8798-L8826)。 |
| **批准 → 真开始（首要阻断）** | 未来由同一次主人确认走原生精确承接，不由模型重新提出调用。用原父执行身份、原未派发操作、未消费决定、`planRef/planHash`、原模型与原预算/期限一起防重；保留旧拒收记录，原子领取一次，接原计划的唯一作者，不另开父 run。只有确定的同一作者 task/run/epoch 开始回执才显示「作者已开始」；存了批准就只说「批准已保存，尚未核对开始」。 | 现在普通 Web 只是保存决定，宿主尝试排队，泛化续接会新建父执行且可重选会话模型；只有附件有专门准确接回例程。不能借这条链、模型重猜、当前默认模型、备用路由或已消费决定补位。原模型只能由原生精确重核，沿用工作配置 model pin 时须全字段一致；缺 pin、源撤回、额度失效、进后台后旧审阅失效、停止/未知结果均不派发或重试，只查原记录。见 [Web 决定](../../app/src/main/kotlin/dev/pocketengine/ui/web/PocketWebTaskActions.kt#L51-L64)、[通用续接](../../app/src/main/java/dev/pocketengine/EngineApplication.java#L4590-L4610)、[新父执行](../../app/src/main/java/dev/pocketengine/EngineApplication.java#L3884-L3892)、[仅附件绑定准确调用](../../app/src/main/java/dev/pocketengine/EngineApplication.java#L3952-L3957)、[模型绑定](../../app/src/main/java/dev/pocketengine/features/controlplane/NativeWorkProfileHost.java#L365-L409)、[TeamParentHost 默认回落](../../app/src/main/java/dev/pocketengine/features/teams/TeamParentHost.java#L33-L42)。 |
| **作者 → 一份真正保存的差异** | 沿原团队的冻结作者/assignment 与实际工件。复用单稿的「完整读这一个固定文本 → 核原 SHA → 完整改稿 → 双 SHA 与回读」和差异界面；团队接入必须保持独立角色权限，模型只获这一个被选文件，不继承普通 B4 的目录查询范围。以一次原生持久结果为准，不另保存第二份正文。 | B4 的私有草稿写入明确排除团队/父任务字段，不能拿团队子任务冒用，也不放宽此门；只复用校验与差异语义。无回执、换成员/assignment、读不全、无实际改动、文字自报均不是交付。见 [固定原文](../../app/src/main/java/dev/pocketengine/features/local/project/FixedProjectDraftSource.java#L43-L52)、[单稿校验](../../app/src/main/java/dev/pocketengine/features/local/project/ProjectEditDraft.java#L19-L60)、[B4 写入边界](../../app/src/main/java/dev/pocketengine/store/TaskStore.java#L13235-L13256)、[团队冻结结算](../../app/src/main/java/dev/pocketengine/store/TaskStore.java#L10262-L10268)。 |
| **差异 → 原项目与原对话** | TaskStore 从同一私有来源发布一个只读定位：原消息 ID/版本、原父 task/run/epoch、project/checkout、plan/approval、冻结成员和 assignment/作者 run/epoch、artifact/path/双 SHA。两边挂同一定位，重新打开仍核这一个原件；复用原项目的工作入口、原话回程和差异阅读。概览只给「某某已保存独立改稿」，不携带正文。 | 原项目不能用只接「完整独审的整树首版」的旧入口代替；对象变化或来源撤回即不展示，不搜索最新稿、切换对话或发新消息。见 [当前原项目团队目录](../../app/src/main/java/dev/pocketengine/store/TaskStore.java#L11313-L11354)、[App 项目工作/原话回程](../src/App.tsx#L2068-L2077)、[原话定位重核](../src/App.tsx#L3023-L3078)、[现有差异窗口](../src/ProjectDraftDifference.tsx#L35-L65)。 |

**交接验收（尚未执行）：**先用当前「只出改稿和差异」走通一次原对话与原项目的单稿回程，不称团队作者。A 实现后再用一份中性本机项目验证：同一原计划明确确认一次；批准行不冒充已启动；只有一位作者的实际原件；两入口核对同一 artifact 与前后 SHA，原项目字节不变。重复点击、切换模型或原文件换版时不产生替代执行；无原件即不显示已交付。已有整树首版的文件许可仍只登记，[独立整合闸门](../../app/src/main/java/dev/pocketengine/store/TaskStore.java#L11550-L11556)保留。
