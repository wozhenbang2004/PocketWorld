# PocketWorld consumer theme source map

`product.css` is the product consumer skin loaded after the existing UI styles. It is an adaptation of already approved and retained controls, not a claim that these consumer overrides are upstream source. It adds no UI framework, controls, markup, task data, or interaction implementation. Original files and existing source manifests are unchanged by this skin.

The composition contract is the final “当前返工：手机产品整体构图” section of `uiux_implementation_v7.md`. The CI20 assembly is rejected evidence, not an approved visual reference. Its `412-01-empty.png` and `412-16-form-controls.png` were inspected for this change: mixed control scales, heavy field fills, repeated floating panel treatment, and double navigation were present. Page structure, route hierarchy, project menus, and task read-model changes belong to the separate App/Secondary owners; this skin does not override their `.pw-page` or `.pw-task-*` geometry.

Colors are solid white/neutral gray; alpha is used only for shadows. This is a role-based theme: ordinary content stays on its page surface; field shells have low elevation; temporary popup surfaces have stronger elevation; the selected physical primary action retains its own source material stack. The file does not add a global animation, universal grayscale filter, layout card, clipping rule, fake status, or hidden information.

Validation for this file is limited to balanced CSS delimiter/quote checks, neutral-color and ownership checks plus source-hook inspection. No full CSS parser or browser was available locally. A fresh GitHub CI rendering and a human review of the composed 360px / 412px screens and motion are still required. This document does not claim aesthetic acceptance, Android device validation, or real-task integration from those checks.
